#  Clone da Tela de Cadastro do Instagram

Este projeto é um clone da tela de registro do Instagram, desenvolvido com **HTML** e **Tailwind CSS**, como parte dos estudos práticos no curso da plataforma **DevClub**, seguindo o tutorial do professor **Rodilfo Mori**.

##  Objetivo

Aprender Tailwind CSS na prática, explorando:
- Estruturação semântica com HTML
- Criação de layouts responsivos usando utilitários do Tailwind
- Otimização da produtividade no desenvolvimento front-end
